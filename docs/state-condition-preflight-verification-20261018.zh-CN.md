## 本轮结论与边界

- 执行前非必要预测造成误杀的修复，在完整链路离线正负例及真机“预测列表、实际画布”样例中通过；本轮观测到的误耗失败预算为 0。负例没有靠宽泛放行来换取正例成功，显式子页、错误应用/工具、菜单仍开及不完整 Home 均保留拒绝。
- 三轮自主任务成功率仍仅 1/3。Home 手势、应用切换器状态和搜索入口定位会造成实际失败；本轮未将这些问题伪装成已修复，也未增加专用操作脚本或工具栏扫描。目的状态/必要条件仍依赖 DS 判断，本轮小样本不构成全面语义可靠性保证。
- 恢复的新鲜度与确认后才规划的链路保留：成功路径通过复测，错误画面会停止；不宣称所有 Home 动作必然成功。
- 最终独立复核对过程型目标的限制保持原样；本轮用明确最终可见目标避免混入该问题。没有重跑完整笑脸，首轮笑脸失败结论继续有效。
- 最终服务在线、设备和镜像正常、baseline ready、Agent 空闲。所有修改仍只在本地，未提交、推送或发布。
